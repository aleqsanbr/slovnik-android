# Словник для Android

Android-приложение для [«Словника»](https://claude.ai/artifact/L2DuyM3QrRJHowUuoqp6mh) — артефакта на claude.ai для заучивания английских слов и фраз из книг: интервальные повторения в обе стороны и вперемешку, наборы, разбор списков слов через Claude, синхронизация между устройствами.

Сам «Словник» живёт на claude.ai и работает в любом браузере. Приложение — тонкая оболочка над ним, которая делает его похожим на нативное:

- открывает «Словник» без интерфейса браузера и прячет шапку claude.ai;
- красит статус-бар и нижнюю панель в цвета страницы, то есть в выбранный в «Словнике» цвет Material You, и отдаёт странице системный акцент;
- иконка в цветах обоев (Android 12+) с поддержкой тематических иконок (Android 13+);
- ярлыки по долгому нажатию на иконку: «Добавить слово», «Повторить», «Словарь»;
- работает без сети (см. ниже);
- любые ссылки за пределы «Словника» открывает во внешнем браузере.

## Установка

Скачай последний APK из [Releases](https://github.com/aleqsanbr/slovnik-android/releases) и установи. Обновляться удобно через [Obtainium](https://github.com/ImranR98/Obtainium): добавь в него ссылку на этот репозиторий.

Нужен Android 10 или новее.

## Вход в Claude

Входи по почте: вход через Google во встроенном браузере Google блокирует. Ссылку из письма открой в обычном браузере — он покажет код, его и введи в приложении.

## Без сети

Пока «Словник» открыт онлайн, приложение хранит у себя копию словаря и самой страницы (страница отдаёт свой код при каждом открытии). Если при запуске нет сети или claude.ai не загрузился, открывается эта копия: можно добавлять, править и повторять слова. Изменения копятся в приложении и уходят в облако, когда онлайн-версия откроется снова — сама при возвращении в приложение с сетью или по кнопке «Сеть есть, синхронизировать». Автоперевод без сети не работает.

Копия страницы в `app/src/main/assets/slovnik.html` нужна только на случай, если приложение ещё ни разу не открывалось с сетью.

## Ограничения

- Экспорт словаря — через кнопку «Показать JSON» и копирование текста: скачивание файлов из встроенного браузера не поддерживается. Импорт JSON работает через системный выбор файла.
- Если Claude показывает своё окно (например, запрос разрешения), шапка claude.ai на это время возвращается, чтобы окно было видно целиком.

## Сборка

Каждый пуш в `main` собирает APK в GitHub Actions и публикует его в Releases. Сборка подписывается ключом из секрета `KEYSTORE_B64` (base64 файла `release.jks`, алиас `slovnik`).

Локально: Android SDK (проще всего через Android Studio) и Gradle 8.9+. Положи ключ в `keystore/release.jks` (он в `.gitignore`) и выполни:

```
gradle assembleRelease
```
