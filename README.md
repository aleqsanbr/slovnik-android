# Словник для Android

Тонкая обёртка над артефактом «Словник» на claude.ai: открывает его без интерфейса браузера и без шапки claude.ai, красит системные панели под тему страницы, подхватывает цвета Material You для иконки и темы.

## Как получить APK

Каждый пуш в `main` запускает GitHub Actions. Готовый APK появляется в **Releases** репозитория (и в артефактах запуска).

Собрать у себя: нужен Android SDK (проще всего через Android Studio) и Gradle 8.9+:

```
gradle assembleRelease
```

APK будет в `app/build/outputs/apk/release/app-release.apk`.

## Установка и обновления

- Скачай APK из Releases на телефон и установи (разреши установку из этого источника).
- Обновления удобно ставить через [Obtainium](https://github.com/ImranR98/Obtainium): добавь ссылку на репозиторий. Для приватного репозитория Obtainium попросит GitHub-токен с доступом на чтение.
- Все сборки подписаны одним ключом (`keystore/release.jks`), поэтому обновляются поверх без потери входа. **Не теряй этот ключ** и держи репозиторий приватным, раз ключ лежит в нём. Для публичного репозитория удали `keystore/` из git и положи ключ в секрет `KEYSTORE_B64` (base64 файла).

## Вход в Claude

Входи по почте. Вход через Google внутри встроенного браузера Google блокирует.

## Что умеет

- Ярлыки по долгому нажатию на иконку: «Добавить слово», «Повторить», «Словарь».
- Тематическая иконка (Android 13+) и цвета иконки из обоев (Android 12+).
- Цвет статус-бара и навигации берётся со страницы.
- Импорт JSON через системный выбор файла. Экспорт: кнопка «Показать JSON» на странице, скачивание файлов из WebView не поддерживается.
- Если claude.ai показывает своё окно (например, разрешение на вызов Claude), приложение временно возвращает обычный вид страницы, чтобы окно было видно.
